# JLPT N4 Japanese Infographics Hub

A clean, modern static website that curates free JLPT N4 level Japanese infographics and study resources.

## What's Included

- **Home / Hero** – Overview of N4 requirements and quick stats
- **Vocabulary section** – Links to free vocab infographics & PDFs
- **Grammar section** – Visual grammar resources
- **Kanji section** – Stroke order sheets and frequency checklists
- **Full resource table** – All recommended free sites in one place
- **Study tips** – How to use infographics effectively

## Sources Curated

- Japanesetest4you.com (individual free infographics)
- Hanabira.org (free PDFs)
- Japademy (kanji checklist)
- JLPT Mastery (vocabulary PDF)
- MLC Japanese
- Edewakaru (picture grammar)
- Iku Channel (worksheets)
- Pinterest

## How to Use

1. Open `index.html` in any modern browser
2. Or host the three files (`index.html`, `styles.css`, `script.js`) on any static hosting (GitHub Pages, Netlify, Vercel, etc.)

No build step or dependencies required.
